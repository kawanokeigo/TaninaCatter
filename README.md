# ⚔️ M5-TaskKill (仮名)

M5StickC Plusを「刀」に見立てて勢いよく振ることで、PCのアプリやChromeのタブを物理的に斬って（強制終了させて）しまう新感覚のタスクキルアプリです！

## 🏗️ システムの3つの構成

1. **M5StickC Plus (コントローラー)**
   内蔵センサーで「傾き」や「振る動作」を感知し、Bluetooth(BLE)でPCに送信します。
2. **PCアプリ (Electron + React)**
   デスクトップに常駐する透明なアプリ。M5Stickからの命令を受け取り、PCのプロセス（.exe）を強制終了させます。
3. **Chrome拡張機能**
   対象が「ブラウザのタブ」の時に活躍。PCアプリと連携して、指定したタブを閉じます。

## ⚙️ アプリの仕組みと遊び方

* **ターゲットを選ぶ**
  PCの起動中アプリ（またはタブ）のリストを自動取得。M5Stickを上下に傾けると、画面上のカーソルが動いてターゲットを選べます。
* **間違って斬らないための「除外リスト」**
  絶対に消したくないアプリは、右クリックメニューの「ブラックリスト」に入れておくことでリストから隠せます。
* **振ってタスクキル！**
  M5Stickを勢いよく振ると、PC画面上の刀がシュッと振り下ろされるアニメーションとともに、ターゲットのアプリが強制終了されます。

## 📂 フォルダ構成

コードはスッキリ管理できるよう、役割ごとにファイルを分けています。

```text
src/
 ├─ main/           # 裏側の処理 (リスト取得、タスクキル実行など)
 ├─ preload/        # 画面側と裏側をつなぐ中継役
 └─ renderer/       # 画面側の処理 (React)
     ├─ App.jsx     # メインロジック (BLE通信や状態の管理)
     └─ components/ # 画面のパーツ (接続ボタン、リスト、刀、設定画面)
