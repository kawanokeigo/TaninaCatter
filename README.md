# ⚔️ M5-TaskKill

M5StickC Plusを「刀」に見立てて勢いよく振ることで、PCのアプリやChromeのタブを物理的に斬って（強制終了させて）しまう新感覚のタスクキルアプリです！

## 🏗️ システムの3つの構成

1. **M5StickC Plus (ハードウェア / コントローラー)**
   * 内蔵センサーで「傾き」や「振る動作」を感知し、Bluetooth (BLE) 経由でPCにコマンドを送信します。
2. **PCデスクトップアプリ (Electron + React)**
   * 画面の端に常駐する透明なミニウィンドウ。M5Stickからの命令や、右クリックメニュー・タスクトレイからの操作を受け付けます。
   * WebSocketサーバー（ポート `8088`）を内蔵しており、Chrome拡張機能とリアルタイムに通信します。
3. **Chrome拡張機能**
   * 対象が「ブラウザのタブ」の時に活躍。PCアプリと連携して、指定したタブをダイレクトに閉じます。

## ⚙️ アプリの機能と特徴

* **選べるターゲットモード**
  * **PCプロセスモード**: 起動中のアプリ（`.exe`）のリストを自動取得してターゲットにします。
  * **Chromeタブモード**: ブラウザで開いているタブのリストを取得し、ブラウザのタブを直接斬ることができます。（※システム系プロセスや除外リストのアプリは自動で保護されます）
* **間違って斬らないための「ブラックリスト（除外設定）」**
  * 絶対に消したくないアプリは、トレイメニューなどからブラックリストに追加してリストから隠せます。
* **物理で斬る爽快感！**
  * M5Stickを勢いよく振ると、画面上の刀がシュッと振り下ろされるアニメーションとともに、ターゲットが強制終了されます。

## 📂 プロジェクトのフォルダ構成

```text
2026-Team-27/
 ├─ electron-app/       # デスクトップアプリの本体 (Electron + React)
 │   ├─ src/
 │   │   ├─ main/       # 裏側の処理 (プロセス取得、WebSocket、タスクキル実行)
 │   │   ├─ preload/    # 中継役
 │   │   └─ renderer/   # 画面側の処理 (React, コンポーネント, 刀アニメーション)
 │   └─ package.json
 ├─ chrome-extension/   # Chrome拡張機能のコード
 └─ m5-firmware/        # M5StickC Plus側のコード

```

 🚀 開発の始め方 (Development)
Electronアプリのディレクトリに移動して起動します。

Bash
cd electron-app

# 依存関係のインストール（初回のみ）
npm install

# 開発モードで起動
npm run dev
📦 配布用アプリ(.exe)のつくりかた
ダブルクリックで単体起動できるWindows用実行ファイルやインストーラーを作成します。

Bash
cd electron-app

# ビルド実行（distフォルダに .exe が生成されます）
npm run build:win
※ 起動時に 8088 ポート（WebSocket）のアクセス許可を求めるアラートが出た場合は、「アクセスを許可する」を選択してください。

🔌 Chrome拡張機能の導入方法
Google Chromeを開き、 chrome://extensions/ にアクセスします。

画面右上にある 「デベロッパー モード」 をONにします。

左上の 「パッケージ化されていない拡張機能を読み込む」 をクリックし、プロジェクト内の chrome-extension フォルダを選択します。
